# NoPSN (DPI using PS4 Browser)

A project to facilitate direct package installation (DPI) on a PlayStation 4 console by leveraging its web browser and local network capabilities.


## 📋 Project Status & To-Do List

The project is currently in its early development stages. Here are the planned features and improvements:
